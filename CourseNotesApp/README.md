# 课程笔记（macOS App）

点一下开始录制网课。听到「下课 / 拜拜」等结束语后，App 会自动停止，并生成这节课的**录音 + 转写稿 + Word 课程总结**。总结里包含 ⭐ Highlight 知识点，每条都标注了第几分钟。

- **直接录电脑声音**：用系统的 ScreenCaptureKit 录制，不需要装 BlackHole，可以戴耳机，也可以静音
- **转写在本机完成**：用 macOS 26 自带的语音识别，不联网，10 分钟的音频几秒就能转完
- **总结模型自己选**：DeepSeek、通义、智谱、豆包、Kimi、Claude 都行，也可以接任何兼容 OpenAI 接口的服务。API Key 存在钥匙串里
- **导入已有录音**：按 ⌘O 选一段音频或视频，同样会转写并生成总结

## 系统要求
- macOS 26 或更高版本，Apple 芯片（M1 及以后）
- 首次转写时，系统会自动下载中文语音模型（由 macOS 管理，只需一次）

## 安装（给用户）
1. 打开 `课程笔记-1.0.0.dmg`，把「课程笔记」拖进「应用程序」
2. 第一次打开时，如果提示「无法验证开发者」：到「系统设置 → 隐私与安全性」，滚到最下面点「仍要打开」。也可以在终端执行 `xattr -cr /Applications/课程笔记.app`
3. 第一次录制「电脑声音」时会请求「屏幕与系统录音」权限：打开后**退出并重新打开 App**
4. 点 App 里的「设置…」，选一个模型并粘贴 API Key，再点「测试连接」确认能用

## 使用
1. 输入课程名，选录制来源（电脑声音 / 麦克风）和总结模型
2. 点红色按钮（⌘R）开始，然后正常上课
3. 听到结束语后会出现倒计时，默认 3 分钟后自动结束。可以点「继续录制」取消，或点「立即结束」
4. 结束后，左侧会出现这节课。点开可以看总结、转写稿，播放录音，或打开 Word

每节课保存为一个文件夹，默认位置是 `~/Documents/课程笔记/`，可以在设置里修改：

| 文件 | 内容 |
|---|---|
| `录音.m4a` | 完整录音 |
| `transcript.md` | 带时间戳的转写稿 |
| `summary.md` | 课程总结（Markdown） |
| `日期_课程名_课程总结.docx` | Word 版总结：Highlight 表、大纲、重点、待办、待查证 |

## 开发者：编译和打包

```bash
cd CourseNotesApp
swift build                  # 调试编译
scripts/build_dmg.sh         # 生成 dist/课程笔记.app 和 dist/课程笔记-<版本>.dmg
VERSION=1.1.0 scripts/build_dmg.sh
```

- 只需要 Xcode Command Line Tools，不需要完整的 Xcode
- 目前用 ad-hoc 签名，所以别人第一次打开时要手动「仍要打开」。要正式分发、双击就能打开，需要 Apple Developer ID（每年 99 美元）：签名后再 `notarytool` 公证
- ad-hoc 签名每次编译都会变：开发机上的「屏幕与系统录音」权限每次都要重新授权一次，钥匙串里的 API Key 也可能读不到，需要重新粘贴
- 同一个 DMG 分发出去不受影响；但发**新版本**给别人时，对方升级后同样要重新授权，可能还要重新粘贴 API Key。用 Developer ID 签名后就没有这个问题

代码结构：
- `Core/`：设置与钥匙串、模型调用（`LLMClient`）、提示词、下课检测（`EndDetector`）、录制流程（`RecordingSession`）、课程文件夹管理
- `Audio/`：电脑声音和麦克风采集、写 m4a、系统语音转写
- `Export/`：Markdown 转 HTML（应用内预览）、Markdown 转 docx（自己生成 OOXML）
- `UI/`：主窗口、录制页、课程详情、设置
